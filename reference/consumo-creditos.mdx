<Info>

</Info>

Cada diligência emitida pela API consome créditos conforme as regras abaixo. A cobrança acontece no momento da emissão, uma única vez por diligência.

## Tabela de consumo

Uma diligência aceita no máximo **2 comarcas**.

| Cenário | Créditos |
|---------|----------|
| Certidões de 1 comarca | 1 |
| Certidões de 2 comarcas no <ins>mesmo estado</ins> | 1 |
| Certidões de 2 comarcas em <ins>estados diferentes</ins> | 2 |
| Somente Análise DiHub | 1 |
| Certidões + Análise DiHub | +0,5 sobre o valor das certidões |

Exemplos:

- 1 comarca + Análise DiHub = **1,5 crédito**
- 2 comarcas no mesmo estado + Análise DiHub = **1,5 crédito**
- 2 comarcas em estados diferentes, sem Análise DiHub = **2 créditos**
- 2 comarcas em estados diferentes + Análise DiHub = **2,5 créditos**

## Regras

- **Saldo usado:** entram na conta os créditos válidos do usuário dono do token e da organização dele. Créditos vencidos não contam.
- **Ordem de consumo:** os créditos com vencimento mais próximo são consumidos primeiro.
- **Saldo insuficiente:** a emissão é recusada com HTTP `400` e nenhum crédito é consumido. A resposta informa os créditos necessários e o saldo disponível:

```json
{
  "statusCode": 400,
  "message": "Not enough credits",
  "data": {
    "requiredCredits": 1.5,
    "totalCreditsAmount": 1
  }
}
```

## Análise DiHub para menor de idade

Para CPF, a Análise DiHub só é feita se o titular tiver 18 anos ou mais.

- **Certidões + Análise DiHub:** as certidões são emitidas e o 0,5 crédito da análise não é cobrado.
- **Somente Análise DiHub:** a API retorna HTTP `400` (`Análise não realizada: usuário menor de idade.`) e nenhum crédito é consumido.

<Note>
  A consulta de saldo (`GET /credits/balance`) não consome créditos.
</Note>
