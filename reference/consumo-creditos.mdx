Cada diligência emitida pela API consome créditos conforme as regras abaixo. A cobrança acontece no momento da emissão, uma única vez por diligência.

## Tabela de consumo

Uma diligência aceita no máximo **2 comarcas**.

| Cenário | Créditos |
|---------|----------|
| Certidões de 1 comarca | 1 |
| Certidões de 2 comarcas no <ins>mesmo estado</ins> | 1 |
| Certidões de 2 comarcas em <ins>estados diferentes</ins> | 2 |
| Somente Análise DiHub | 1, ou o valor da sua condição comercial |
| Certidões + Análise DiHub | +0,5 sobre o valor das certidões |

Exemplos:

- 1 comarca, sem Análise DiHub = **1 crédito**
- 1 comarca + Análise DiHub = **1,5 crédito**
- 2 comarcas no mesmo estado + Análise DiHub = **1,5 crédito**
- 2 comarcas em estados diferentes, sem Análise DiHub = **2 créditos**
- 2 comarcas em estados diferentes + Análise DiHub = **2,5 créditos**

## Condição comercial da Análise DiHub

Pedida sozinha, a Análise DiHub custa 1 crédito. Assinaturas com condição comercial negociada pagam de 0,5 a 1 crédito, e vale a assinatura do saldo que paga a diligência: a sua, quando paga o seu saldo, ou a da organização, quando paga o saldo dela. O valor é o mesmo na API e no [app](https://app.dihub.com.br). Os demais cenários da tabela não mudam.

## Regras

- **Saldo usado:** um saldo só paga cada diligência. Primeiro o do usuário dono do token, se cobrir o valor; senão o da organização dele, se cobrir. Os dois não se somam. Créditos vencidos não contam.
- **Ordem de consumo:** os créditos com vencimento mais próximo são consumidos primeiro.
- **Saldo insuficiente:** a emissão é recusada com HTTP `400` e nenhum crédito é consumido. A resposta informa os créditos necessários e a soma dos dois saldos, que pode ser maior que o necessário quando nenhum deles cobre o valor sozinho:

```json
{
  "statusCode": 400,
  "message": "Not enough credits",
  "data": {
    "requiredCredits": 1.5,
    "totalCreditsAmount": 1
  }
}
```

- **Créditos congelados:** se o saldo que pagaria tem créditos congelados por pendência de pagamento, a emissão é recusada com HTTP `400` (`Credits are frozen`, código `FROZEN_CREDITS`) e nenhum crédito é consumido.

## Análise DiHub para menor de idade

Para CPF, a Análise DiHub só é feita se o titular tiver 18 anos ou mais.

- **Certidões + Análise DiHub:** as certidões são emitidas e o 0,5 crédito da análise não é cobrado. A diligência custa 1 crédito (2 com comarcas em estados diferentes).
- **Somente Análise DiHub:** a API retorna HTTP `400` (`Análise não realizada: usuário menor de idade.`) e nenhum crédito é consumido.
