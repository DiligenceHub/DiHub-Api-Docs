<Warning>
  A API da DiHub ainda não envia webhooks. Não há cadastro de URL nem notificação de eventos.
</Warning>

Para saber quando uma diligência terminou, consulte o status periodicamente:

1. Emita a diligência com [`POST /diligences/emit`](/api-reference/diligences/emit) e guarde o `diligenceId` retornado.
2. Consulte [`GET /diligences/{id}/status`](/api-reference/diligences/status) em intervalos até o processamento terminar.
3. Baixe os arquivos com [`GET /diligences/{id}/download-zip`](/api-reference/diligences/download-zip) ou [`GET /diligences/{id}/download-pdf`](/api-reference/diligences/download-pdf).
