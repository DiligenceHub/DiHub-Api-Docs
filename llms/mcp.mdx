O servidor MCP da documentação deixa o assistente de IA buscar e ler as páginas desta documentação durante a conversa, em vez de você copiar trechos manualmente.

## Endpoint

```
https://docs.dihub.com.br/mcp
```

Transporte HTTP, sem autenticação.

## Configuração

### Claude (web e desktop)

Em **Configurações → Conectores → Adicionar conector personalizado**, informe a URL do endpoint.

### Claude Code

```bash
claude mcp add --transport http dihub https://docs.dihub.com.br/mcp
```

### Cursor

Adicione ao `.cursor/mcp.json` do projeto (ou ao `~/.cursor/mcp.json`):

```json
{
  "mcpServers": {
    "dihub": {
      "url": "https://docs.dihub.com.br/mcp"
    }
  }
}
```

### Outros clientes

Qualquer cliente compatível com MCP via HTTP aceita a URL do endpoint.

## Ferramentas expostas

| Ferramenta | O que faz |
|------------|-----------|
| `search_di_hub_documentation` | Busca nas páginas da documentação |
| `query_docs_filesystem_di_hub_documentation` | Lê o conteúdo das páginas |
| `submit_feedback` | Envia ao time da DiHub um aviso sobre página errada ou incompleta |

<Note>
  O MCP dá acesso só à documentação. Ele não chama a API da DiHub, não emite diligências e não consome créditos. Para chamar a API, use o seu token normalmente.
</Note>
