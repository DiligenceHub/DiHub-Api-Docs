## Quando usar cada um

|                    | MCP Server                                  | llms.txt                                       |
| ------------------ | ------------------------------------------- | ---------------------------------------------- |
| **Objetivo**       | O assistente busca o que precisa            | Toda a documentação como contexto              |
| **Ideal para**     | Uso contínuo (Claude, Cursor)               | Prompt pontual ou ferramenta sem MCP           |
| **Formato**        | Servidor MCP via HTTP                       | Arquivo de texto                               |
| **Configuração**   | URL do endpoint no cliente MCP              | Cole o conteúdo ou aponte a URL                |
