---
title: 'Emitir diligência'
description: 'Cria uma diligência para emissão de certidões e/ou Análise DiHub'
openapi: 'POST /diligences/emit'
---

## Regras

- Os créditos são debitados na criação. A emissão das certidões é assíncrona: acompanhe com `GET /diligences/{id}/status`.
- Máximo de 2 comarcas por requisição.
- UFs liberadas na API: **AL, BA, CE, DF, ES, GO, MA, MG, MS, PA, PB, PE, PI, RJ, RS e SP**. Pegue os valores de `state` e `district` em [`GET /diligences/districts`](/api-reference/diligences/districts).
- As certidões emitidas em cada UF estão em [Certidões e emissores](/reference/todas-certidoes).
- `document` aceita CPF ou CNPJ, com ou sem pontuação. O CNPJ pode ser alfanumérico; os dígitos verificadores do CNPJ são validados.
- Para CPF, a Análise DiHub só é feita se o titular tiver 18 anos ou mais.
- Cobrança por cenário: [Consumo de créditos](/reference/consumo-creditos).

## Cenários

<AccordionGroup>
  <Accordion title="Certidões">
    ```json
    {
      "document": "12345678901",
      "documentIdentity": "MG12345678",
      "districts": [
        { "state": "MG", "district": "BELO_HORIZONTE" },
        { "state": "SP", "district": "SAO_PAULO" }
      ]
    }
    ```
    - `districts` é obrigatório, com 1 ou 2 comarcas.
    - `documentIdentity` (RG) é opcional e só vale para CPF.
  </Accordion>
  <Accordion title="Certidões + Análise DiHub">
    ```json
    {
      "document": "12345678901",
      "districts": [
        { "state": "MG", "district": "BELO_HORIZONTE" }
      ],
      "creditAnalysis": true
    }
    ```
    - Titular menor de 18 anos: as certidões são emitidas, a análise não é feita e não é cobrada.
  </Accordion>
  <Accordion title="Só Análise DiHub">
    ```json
    {
      "document": "12345678901",
      "creditAnalysisOnly": true
    }
    ```
    - Dispensa `districts`.
    - Titular precisa ter 18 anos ou mais.
    - Custa 1 crédito.
  </Accordion>
</AccordionGroup>

## Erros

Todos os erros abaixo acontecem antes do débito: nenhum crédito é consumido.

<AccordionGroup>
  <Accordion title="400 - Corpo inválido">
    `message` traz o primeiro problema encontrado e `data` traz a lista completa, com `path` indicando o campo. Exemplos: `O documento deve ter 11 ou 14 caracteres (CPF ou CNPJ)`, `CNPJ inválido: dígito verificador não confere`, `Máximo de 2 distritos`, `Distritos são obrigatórios quando não é apenas Análise DiHub`.
  </Accordion>
  <Accordion title="400 - Comarca inválida">
    `Invalid district <COMARCA> in state <UF>`: a comarca não existe na UF informada. Use os valores de [`GET /diligences/districts`](/api-reference/diligences/districts).
  </Accordion>
  <Accordion title="400 - Créditos insuficientes">
    `Not enough credits`. `data` traz `requiredCredits` e `totalCreditsAmount`. Solicite créditos no [painel financeiro](https://app.dihub.com.br/perfil/financeiro).
  </Accordion>
  <Accordion title="400 - Titular menor de idade">
    `Análise não realizada: usuário menor de idade.` Só ocorre com `creditAnalysisOnly: true`.
  </Accordion>
  <Accordion title="404 - Documento não encontrado">
    `Subject Document Not Found`: o CPF ou CNPJ não foi encontrado nas bases cadastrais. Confira o documento.
  </Accordion>
  <Accordion title="422 - CPF sem data de nascimento">
    `Data de nascimento não disponível para o CPF informado.`
  </Accordion>
</AccordionGroup>
