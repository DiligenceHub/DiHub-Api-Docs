<Warning>
Hoje a API emite apenas para **BA, DF, ES, GO, MG, MS, PE, RJ, RS e SP**. Este endpoint também lista comarcas de UFs que ainda não estão liberadas na API, e pedir emissão nelas retorna erro. Confira as UFs disponíveis em [Certidões e emissores](/reference/todas-certidoes).
</Warning>

## Como usar

A resposta traz, em `data`, um objeto cuja chave é a UF e o valor é a lista de comarcas daquela UF, em ordem alfabética.

Use os valores exatamente como vieram (maiúsculas, sem acento, `_` no lugar de espaço) nos campos `state` e `district` de `POST /diligences/emit`. Comarca que não existe na UF informada gera `400` com a mensagem `Invalid district <COMARCA> in state <UF>`.

## Exemplo de resposta (resumido)

```json
{
  "statusCode": 200,
  "message": null,
  "data": {
    "BA": ["SALVADOR"],
    "DF": ["BRASILIA"],
    "GO": ["ANAPOLIS", "GOIANIA"],
    "MG": ["BELO_HORIZONTE", "CARATINGA", "DIVINOPOLIS", "UBERLANDIA"],
    "RJ": ["RIO_DE_JANEIRO"],
    "RS": ["PORTO_ALEGRE"],
    "SP": ["CAMPINAS", "SAO_PAULO"]
  }
}
```
