## Como usar

Retorna os IDs das diligências criadas pelo usuário dono do token, da mais recente para a mais antiga. Não há paginação nem filtro.

## Próximos passos

Com o ID em mãos:

- **Status** → `GET /diligences/{id}/status`
- **Certidões** → `GET /diligences/{id}/certificates`
- **PDF da diligência** → `GET /diligences/{id}/download-pdf`
- **ZIP da diligência** → `GET /diligences/{id}/download-zip`
- **PDF de uma certidão** → `GET /certificate/{id}/download-pdf`, com o `id` da certidão vindo de `GET /diligences/{id}/certificates`
