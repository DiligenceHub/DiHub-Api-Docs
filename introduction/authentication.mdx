Toda requisição à API da DiHub precisa de um token de API no header `X-Api-Token`. O token identifica o seu usuário: a emissão consome os créditos dele e da organização dele. Sem token válido, a API recusa a requisição com `401`.

```bash
curl 'https://api.dihub.com.br/credits/balance' \
  --header 'X-Api-Token: SEU_TOKEN'
```

## Como criar um token

No [Dashboard DiHub](https://app.dihub.com.br):

<Steps>
  <Step title="Acesse a página de API">
    No menu da sua conta (canto superior direito), clique em **API** para abrir a página **Chaves de API**.

    <Frame>
      <img src="/images/entrar-no-painel-de-api.png" alt="Menu Minha conta com opção API" />
    </Frame>
  </Step>
  <Step title="Crie um novo token">
    Clique em **+ Criar Novo Token**, no canto superior direito.

    <Frame>
      <img src="/images/criar-novo-token.png" alt="Botão Criar Novo Token na página de Chaves de API" />
    </Frame>
  </Step>
  <Step title="Copie o token">
    O token aparece na tabela. Use o ícone de copiar ao lado dele. Você pode copiá-lo de novo sempre que precisar.

    <Frame>
      <img src="/images/copiar-e-salvar-o-token.png" alt="Tabela de tokens com ícone para copiar" />
    </Frame>
  </Step>
</Steps>

Na mesma página você vê os tokens ativos e desativa os que não usa mais.

<Note>
  O token vale por **90 dias** a partir da criação. Depois disso, crie um novo.
</Note>

## Como desativar um token

Clique no ícone de lixeira na coluna **Ações** da tabela de Chaves de API. A desativação é imediata e não tem volta: um token desativado não pode ser reativado.

<Frame>
  <img src="/images/desativar-o-token.png" alt="Ações para desativar token" />
</Frame>

## Erros de autenticação

A API retorna `401` nestes casos:

| Situação | Resposta |
|----------|----------|
| Header `X-Api-Token` ausente | `{"error": "Unauthorized", "message": "Missing or invalid api token"}` |
| Token inexistente, vencido ou desativado | `{"error": "Unauthorized", "message": "Invalid token"}` |

## Boas práticas

- Guarde o token em variável de ambiente ou gerenciador de segredos, nunca no código.
- Não compartilhe o token. A DiHub nunca pede o seu token.
- Desative na hora qualquer token que possa ter vazado.
